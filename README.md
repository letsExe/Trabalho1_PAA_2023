# 📊 Strassen e Problema da Mochila

Repositório desenvolvido para o **Trabalho da disciplina de Projeto e Análise de Algoritmos — UNIOESTE**, no ano de **2023**.

O projeto apresenta a implementação e análise de dois problemas clássicos da computação:

- Multiplicação de Matrizes utilizando o **algoritmo de Strassen**;
- Resolução do **Problema da Mochila**.

---

## 📌 Sobre o Projeto

Este trabalho tem como objetivo estudar, implementar e comparar algoritmos importantes da área de Projeto e Análise de Algoritmos.

A proposta envolve não apenas a implementação dos algoritmos, mas também a análise de desempenho, complexidade e comportamento em diferentes tamanhos de entrada.
